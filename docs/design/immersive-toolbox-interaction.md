# Handling the toolbox

The accepted A arrival stays image-led. In the open collection, a deliberate
“Pick up the toolbox” action loads a real GLB into a bounded canvas. All five
project disclosures and their source links stay native and usable throughout.
The photograph remains the no-JavaScript, GPU-unavailable and error fallback.

The viewer uses existing Three.js dependencies, generated by the repository's
Blender asset pipeline. No model API, third-party asset request, account or
persistence is involved. Vite emits the imported GLB under a content-hashed
`/_astro/` URL covered by immutable headers. Runtime and model are requested
only on activation. DOM controls provide keyboard parity for turning and
opening the actual hinge hierarchy; horizontal dragging uses `touch-action:
pan-y` so vertical page scrolling remains native.

A render-on-demand loop runs while opening/closing or dragging, and settles
when idle. Reduced-motion visitors receive immediate poses. DPR is capped at
1.5, shadow resolution at 1024. Resize and visibility are handled explicitly.
Closing the collection, returning to the photograph or leaving a non-persisted page aborts
pending loads and disposes geometry, materials, textures, environment, shadows,
renderer, listeners and observers. Context loss restores the photograph and
provides a visible retry message. An asynchronous completion moves focus only
when the visitor is still within the viewer; explicit return restores focus
to its initiating button.

Native controls and the loader gate are separate from the rendering adapter.
GLB hinge extras supply local-X ranges and phases; animation multiplies the
imported rest quaternion rather than replacing its authoring rotation. The
production quality guard in the historical gallery is not overridden.

API references: [GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html),
[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer).

## Verified integration

The final imported GLB is 149,396 bytes / 9,916 authored triangles, nine hinges
and 21 primitives. Its SHA-256 is
`ef8e3e31d1f45f915f095a2f25deb067962b9dfc713e8c34d4f478b5dbece180`,
identical to the public authoring copy and final packed proof asset. The raw
export/preflight/proof records all reference
`97fe4ca45e1a3faa77804a84526167c09b0966d7c16aa0f92bdebd1d163d1d4f`.
The authored mechanism passed 101 positions × 343 structural pairs without
surface crossings; minimum tray separation is 3.459 mm. Runtime phase clamps
are linear and identical to that certificate; only the overall time is eased.
Independent decoded geometry/frustum checks covered 101 poses × 17 turns at
seven canvas ratios, with no clipping (maximum absolute NDC 0.874).

The accepted A image-led arrival remains unchanged. Live materials, warm key,
soft shadows, full swept-pose framing and native controls were inspected on
native Chromium at 1440×1000 and 390×844. The model is in the same ceramic/glaze
family, not pixel-identical to the generated photographic room; its simpler
real-time environment is intentional. Phone handling expands the stage to
520 px, leaving the controls below the full object and preserving normal page
scrolling. The default photograph keeps its existing composition and height.

Playwright 1.65.0 with Chromium 158.0.8127.18 / build1254:
11 viewer cases pass, 16 intentional project skips, zero retries. Checks cover
real pixels and hinge endpoints, turning, lazy/no-JS contracts, reduced motion,
failed-load retry, real context loss, cancellation/reopening, focus ownership,
live axe and emulated phone pan behavior. No page or unexpected errors remain;
exact software ReadPixels warnings and deliberately injected failure messages
are preserved in diagnostic artifacts rather than counted as application
failures. Native sampling observes 46 draw calls / 19,838 rendered triangles.

Separate release preflight: 116 pass, 24 intentional skips, zero retries across
Chromium, phone emulation, no-JS and WebKit build2388. A's metadata, navigation,
source links, examples, secondary pages, 320 px reflow and strict-CSP archive
smoke are clean. WebKit screenshot artifacts are omitted because Playwright's
capture helper injects prohibited CSS; every functional/console assertion is
retained, with Chromium screenshots and manual shipping-Safari visual review.
The WebKit native-select CSP regression is fixed by the minimal toolchain
upgrade, validated with both a clean native control and a forbidden-style
negative control. Production policy and controls are unchanged.

Final built budget inventory: 3,909 eager gzip bytes on A, 167,904 lazy gzip
bytes reachable from A, 223,893 distinct lazy gzip bytes across all routes, and
888,308 bytes across all 14 emitted GLBs (both intentional toolbox copies count).
These are inventory costs, not physical-device FPS or cold-network results.

Browser plugin is unavailable; existing Playwright engines were used. Captures
and detailed reports remain outside the repository under `/tmp/toolbox-native`,
`/tmp/immersive-toolbox165-evidence` and `/tmp/immersive-final-preflight-results`.
Hosted exact-head checks are linked in the PR/Notion; do not infer their current
state from a local count. Physical devices, VoiceOver and Matt's final live-object
visual review remain final-testing gates. Main and deployment stay held.
