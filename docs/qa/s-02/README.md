# S02 integration evidence

`bundle.json` is generated by `node scripts/report-budgets.mjs --json` after a
fallback production build. It checks exact model hashes/copies and inventories
static versus dynamic JavaScript dependencies with the same accounting as CI.
These gzip totals are inventories, not measured network transfers.

`native-adapters.json` records actual object raycast / native summary / Enter
parity for both drawers, saved-key and original/copy pebble visibility before and
after clearing, Flagz Cat Off/On, and the opt-in `?qa=1` quality status. There were
no page errors. The renderer was full Chromium using Apple M5 Metal, without the
software-driver capability override.

`render-budget.json` samples all nine settled stops at 390×844, 1440×900 and
2560×900, High quality, Cat on, after visiting all stops. The largest observed
frame is 45 draw calls and 40,684 triangles, below 60 and 150,000 respectively.
This is rendering cost evidence, not an FPS measurement or physical-phone test.
The native screenshot shows the Human Error drum pads after the shadow change.
Inset pads retain their materials, individual touch pivots, animation and received
shadows; the chassis supplies their shared cast silhouette. Before this change,
Human Error cost 61 calls (`native-before-batching.json`). Cat pose batching did
not reduce its already-two-material drawing cost and was not retained.

The full hosted browser/edge suite and three consecutive `pnpm perf` invocations
remain the final CI gate. Physical Android/iPhone smoothness, selected quality,
VoiceOver and real browser zoom remain manual acceptance work for Matt.
